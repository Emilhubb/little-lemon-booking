# Little Lemon Restaurant - Table Booking App

This project is the Capstone project for the Meta Front-End Developer Professional Certificate. It is a web application built with React that allows users to book a table at the Little Lemon restaurant.

## Features
- Responsive UI/UX designed with Little Lemon brand colors.
- Interactive table booking form with validation (date, time, number of guests, occasion).
- Basic unit tests using React Testing Library.
